# pacoalbacetec.dev

Blog personal hecho con [Hugo](https://gohugo.io) y el tema `candil` (en `themes/candil`).

- Escribir: `hugo new content posts/mi-entrada.md`, o crea el `.md` a mano en `content/posts/`.
- Ver en local: `hugo server` → http://localhost:1313
- Publicar: `git push` a `main`. El workflow de `.github/workflows/hugo.yml` lo construye y lo sube a GitHub Pages.
